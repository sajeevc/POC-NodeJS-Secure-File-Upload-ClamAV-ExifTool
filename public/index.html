Scan, strip, then store.

Every upload is virus-scanned with ClamAV, stripped of EXIF and other metadata with ExifTool, then kept only if it is clean.

The EICAR file is a harmless antivirus test signature. It should be rejected and never stored.

Pipeline

  1. Multer writes the file to a temp directory under a size cap.
  2. The path is resolved and rejected if it leaves the app root.
  3. ClamAV scans the bytes. Infected files are deleted immediately.
  4. ExifTool runs -all= -overwrite_original to strip GPS, camera, and document tags.
  5. The sanitized file is copied into local storage and the temp file is removed.
